# Contributor boundaries

Use the pinned tools from mise.toml and Bun. Run bun run check and bun run test:consumer before handoff. Keep component code native checked Blocks, Bindings and implementation Layers; parent operations must not mutate child models. Read the pinned Foldkit Domains reference before changing composition. Preserve source notices and complete motion behavior. SDK changes are limited to the exact patch in patches/foldkit@0.170.0-canary.54f8bcd443b4.patch. Private SDK imports, React runtime, global Motion frame pumping, backend credentials and application services do not belong in these libraries.

Maintain package source only; registry payloads and the public site are generated by bun run build. Keep all registry dependency closures on the same immutable release. Changes to generated import aliases must preserve exact installed versions. Do not commit, push or publish without explicit user instructions. Treat existing changes in other workspaces as user-owned and leave them alone.
